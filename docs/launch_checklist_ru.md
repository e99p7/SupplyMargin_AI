# Checklist перед первым платящим пользователем

## Инфраструктура

- [ ] Домен открывается по HTTPS без предупреждений.
- [ ] PostgreSQL и MinIO недоступны снаружи.
- [ ] `/readyz` возвращает HTTP 200.
- [ ] Настроены ежедневные backup и тест восстановления.
- [ ] Логи ограничены по размеру и не содержат таблицы или секреты.
- [ ] Настроены уведомления о 5xx, failed jobs и нехватке диска.

## Безопасность

- [ ] JWT, PostgreSQL, MinIO и admin-секреты уникальны.
- [ ] `.env` отсутствует в Git и архивах для клиентов.
- [ ] Проверен сценарий «пользователь B открывает ID пользователя A» — 404.
- [ ] Загрузка `.xlsm`, `.exe`, ZIP и слишком большого файла отклоняется.
- [ ] Удаление аккаунта удаляет файлы и записи пользователя.
- [ ] Legacy API key либо отключен, либо хранится только server-side.

## Оплата

- [ ] Выполнен тестовый платеж ЮKassa.
- [ ] Подписка не включается по `return_url` без webhook.
- [ ] Повтор одного webhook не продлевает подписку дважды.
- [ ] Проверяются статус, сумма, тариф и user_id платежа.
- [ ] Есть понятный канал возврата денег и поддержки клиента.

## Продукт

- [ ] CSV и XLSX проходят полный сценарий.
- [ ] После restart API и worker история остается на месте.
- [ ] Модель, manifest, JSON и Excel присутствуют в хранилище.
- [ ] Повторный запуск и новая версия таблицы работают.
- [ ] Ошибочный job можно повторить.
- [ ] Лимиты тарифов проверены.

## ML и юридическая часть

- [ ] Режим запуска — `shadow`.
- [ ] В интерфейсе нет обещания гарантированной прибыли.
- [ ] Подготовлены политика обработки данных и пользовательское соглашение.
- [ ] Определены сроки хранения и порядок удаления данных.
- [ ] Проведена юридическая проверка требований 152-ФЗ и 54-ФЗ.
